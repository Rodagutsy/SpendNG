# Problem Statement

Nigerian earners use multiple financial platforms:

- GTBank
- Access Bank
- Opay
- Kuda
- Moniepoint
- PalmPay
- Grey
- Geegpay

Each platform stores only part of the user's financial history.

When users need:

- tax filing
- expense reporting
- loan applications
- income verification
- spending analysis

they must manually:

- request statements
- scroll through SMS
- search emails
- reconstruct records

This is slow, fragmented, expensive, and inaccurate.

Current solutions fail because they either:

- require unsupported bank APIs
- target foreign markets
- require manual data entry

SpendNG solves this by automatically capturing financial alerts already arriving on users' devices.
