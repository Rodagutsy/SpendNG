# spendng-icons

## Purpose

Defines iconography rules.

Icons support meaning. They never replace meaning.

---

## 1. Icon Library

Approved:

Lucide

Only.

No mixed libraries.

---

## 2. Sizes

| Usage | Size |
|------|------|
| Inline | 16 |
| Buttons | 20 |
| Navigation | 24 |
| FAB | 24 |
| Hero | 32 |

---

## 3. Stroke

Default:

2px

Never modified.

---

## 4. Color

Icons must use design tokens only.

No raw hex values.

---

## 5. Category Icons

Every category must have:

- icon
- label

Never icon-only.

---

## 6. Navigation Icons

Must always pair:

Icon + text label

---

## 7. Status Icons

Required for:

- Success
- Warning
- Error
- Offline

---

## 8. Accessibility

Decorative icons:

Hidden from screen reader.

Interactive icons:

Require labels.

---

## 9. Forbidden

Never:

- Use emoji
- Mix filled + outline styles
- Use color alone
