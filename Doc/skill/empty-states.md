# spendng-empty-state

## Purpose

Defines all empty-state behavior.

An empty state must educate, not blame.

---

## 1. Required Structure

Every empty state contains:

1. Illustration placeholder
2. Headline
3. Supporting text
4. Primary action

Optional:

Secondary action

---

## 2. Layout

Centered vertically.

Maximum width:

320pt

Spacing:

24pt between sections.

---

## 3. Headline Rules

Maximum:

40 characters

Tone:

Clear, direct.

Examples:

- No transactions yet
- Nothing matched your search
- No exports available

---

## 4. Supporting Copy

Maximum:

2 lines

Must explain:

- what happened
- what to do next

---

## 5. Actions

Primary action required.

Examples:

- Import alerts
- Clear filters
- Add manually

---

## 6. Illustration Rules

Must use:

Neutral line illustration.

Never:

Stock photography
Emoji

---

## 7. Search Empty State

Action:

Clear filters

---

## 8. First Use Empty State

Action:

Import transactions

---

## 9. Offline Empty State

Action:

Retry sync

---

## 10. Accessibility

Illustrations must be decorative only.

Exclude from screen reader.
